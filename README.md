# HaatKhata

> **কাজ শেষ, খাতা ফাঁকা** — A task management web app built with Flask.

**[Live Demo](https://haatkhata.onrender.com/)**

## Features

- Secure user authentication
- Task CRUD with priority levels and due dates
- Color-coded categories
- Dashboard analytics
- Advanced search and filtering
- Responsive Bootstrap 5 UI

## Tech Stack

- **Backend**: Flask, Python, Gunicorn
- **Database**: PostgreSQL (production)
- **Frontend**: HTML5, Bootstrap 5, Jinja2
- **Hosting**: Render.com
